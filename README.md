## Overview

splic.co is a desktop video editor that combines natural-language editing with a familiar timeline. You describe the change you want, and the editor applies it as an editable edit on the timeline — so you can keep refining it by hand. AI handles the repetitive work; you keep control of the result.

## The Problem

Video editing is full of small, repeated decisions: trimming silences, tightening pacing, repositioning clips, syncing captions. Doing them manually is slow, and the tools that make them fast come with a steep learning curve. The result is that a lot of editing time goes to mechanical adjustments instead of creative ones.

## What Makes splic.co Different

- **Describe your edits.** Ask for changes in plain language instead of hunting through menus and panels.
- **AI and manual editing share one workflow.** Every AI-assisted change lands on the same timeline you edit directly — nothing happens in a separate, hidden pass.
- **You stay in control.** The AI proposes the edit; you decide what stays, adjust what doesn't, and own the final cut.

## Planned Features

The following are part of the project's direction and are **not yet implemented**:

- Natural-language editing instructions
- Timeline-based manual editing
- Reusable editing templates
- Captions, text, and image overlays
- Short-form video workflows
- Iterative refinement, moving between AI suggestions and manual edits

## Project Status

splic.co is in early development. This repository currently hosts the project's identity while the editor is being built — there is no release, download, or installation method yet. Features listed above are goals, not shipped functionality.
